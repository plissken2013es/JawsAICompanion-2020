# ⚠️ This repository has moved

**The source code of Jaws AI Companion now lives at [github.com/plissken2013es/Jaws](https://github.com/plissken2013es/Jaws).**

This repository is an early snapshot from October 2020 and is no longer maintained. It does not include anything released since then: the Vite build, the Android and iOS packaging with Capacitor, the German and Russian translations, the test suite or recent fixes.

- **Want to contribute** (a translation, a fix, an idea)? Fork the new repository and open your pull request there.
- **Already forked this one?** Your fork won't pick up new changes from here. Fork [the new repository](https://github.com/plissken2013es/Jaws) instead.

## Where to play

- **Web:** https://robojaws.netlify.app
- **Android:** [Jaws Companion App on Google Play](https://play.google.com/store/apps/details?id=com.netlify.JawsCompanion)
- **BoardGameGeek:** [the app's thread in the Jaws forums](https://boardgamegeek.com/thread/2536638/jaws-solo-mode-companion-app-ai-plays-as-the-shark)

Jaws Companion plays the Shark for Act I of the *Jaws* board game (Ravensburger, 2019), so you can play solo or cooperatively. You still need your own copy of the game.
